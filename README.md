# LocateMe

LocateMe is a modern SwiftUI application that allows users to search for cities using the Nominatim API, view locations on an interactive MapKit map, and save favorite locations using Core Data. The app features a unique and attractive design with custom gradients and a minimal aesthetic.

## Features

- **City Search:**  
  Enter a city name in the search screen to fetch results from the Nominatim API.
- **Map View:**  
  Select a location to display it on a MapKit map with a custom pin annotation.
- **Save Favorites:**  
  Easily save locations to Core Data for later retrieval, with confirmation alerts to enhance user feedback.
- **Favorites List:**  
  Browse your saved favorite places on a dedicated screen.

## Technologies

- **SwiftUI** – For building the user interface with a modern and minimal design.
- **MapKit** – For displaying maps and annotations.
- **Core Data** – For persistent local storage of favorite locations.
- **Nominatim API** – To fetch location details based on user input.

## Requirements

- iOS 17.0+
- Xcode 14+
- Swift 5
